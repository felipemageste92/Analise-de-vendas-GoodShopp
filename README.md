# Analise-de-vendas-GoodShopp
Dashboard de análise de vendas desenvolvido no Power BI como aplicação prática do curso Power BI Profissional (65% concluído). Inclui ETL com Power Query, modelagem de dados, medidas DAX, análise de KPIs, comparação temporal (YoY), segmentações interativas e publicação no Power BI Service, com foco em gerar insights para tomada de decisão.


Projeto de Análise de Vendas com Power BI

Contexto

Este projeto foi desenvolvido como aplicação prática dos conhecimentos adquiridos no curso Power BI Profissional – Hashtag Treinamentos, atualmente com 65% do conteúdo concluído até o momento.

Antes de iniciar o módulo de DAX Avançado, optei por pausar o curso para revisar os conceitos estudados até o momento e consolidar o aprendizado por meio da construção de um projeto completo de análise de vendas.



Objetivo

Construir um dashboard analítico capaz de:

Monitorar KPIs comerciais
Identificar padrões de comportamento de compra
Detectar variações sazonais
Apoiar tomadas de decisão com base em dados



Ferramentas e Tecnologias Utilizadas

Power BI Desktop
Power Query (tratamento e transformação de dados)
Processo ETL (extração, transformação e carga)
Modelagem de Dados
Medidas DAX
Storytelling com Dados
Publicação no Power BI Service



Principais Indicadores (KPIs)

Faturamento Total: R$ 956,67 milhões
Ticket Médio: R$ 239,17 mil
Produto com maior faturamento: TV de 50 polegadas
Produto mais vendido: TV de 50 polegadas (323 unidades)



Principais Análises Realizadas

1.Comparação Temporal

Foi identificada uma queda de 32,62% no faturamento no mês de maio.
Após análise, verificou-se que o mês possuía apenas 15 dias registrados, evitando uma interpretação incorreta de tendência negativa.

2.Segmentações Disponíveis

O dashboard permite análise interativa por:

Cidade
Faixa etária
Período (datas)
Método de pagamento
Status de fidelidade

3.Experiência do Usuário

O layout foi desenvolvido com foco em:

Clareza visual
Hierarquia de informações
Navegação entre páginas por botões laterais
Filtros interativos para exploração dinâmica dos dados



Publicação:

O projeto foi publicado no Power BI Service, permitindo compartilhamento e acesso online ao relatório.



Resultado:

Este projeto consolidou conhecimentos em:

Transformação e modelagem de dados
Construção de métricas em DAX
Análise exploratória
Interpretação estratégica de indicadores
Estruturação de dashboards orientados à tomada de decisão

O objetivo principal foi transformar dados brutos em informações acionáveis por meio de uma abordagem estruturada e analítica.
